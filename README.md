# ICASSP 2027 Special Session Website

Static, responsive website for the proposed ICASSP 2027 Special Session:

**Security and Trustworthiness of AI-Driven Signal and Structured Data Processing**

## Local preview

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000` in a browser.

## GitHub Pages

The site has no build step. Publish the contents of this directory from the repository root or from a GitHub Pages deployment branch.
